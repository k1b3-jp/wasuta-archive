## 保存モデル

`archive_research` スキーマにaccounts、account_identifiers、source_records、source_versions、source_observations、source_contributors、passages、account_evidence、editorial_proposals、coverage_runs、collection_auditを追加した。

- 既存events/members/songsのIDを参照する。公演IDなしの原資料を保存できる。
- 原資料と編集要約を分離。元の公開日時・観測日時・指標の観測日時も分離する。
- Xの投稿IDとユーザーIDは文字列。JavaScriptの整数丸めを避ける。
- 同一投稿IDは同一原資料。取得本文等の指紋で版を分け、いいね数等の変化は本文の訂正として数えない。指紋は取得した表現の違いであり、X上の編集があったという断定ではない。
- 長文はnote_post（旧形式note_tweetも読取可）を優先。引用・返信・リポストの参照と編集履歴IDは返却された範囲で保持。記事型の全文未取得はpartialを表示する。
- 調査スキーマはPostgRESTの公開対象に含めない。匿名・authenticated・service_roleへスキーマ使用権や表の権限を付けず、RLSも有効にする。今回の取り込みは固定したローカルDBの所有者だけが実行する。既存sourcesへ未承認書誌を投入しない。
- 自動公開機能はない。表示用の事実記述・文章・展示構成への移行、管理画面からの研究データレビューは後続作業。

X本文はGitやpublicフォルダに保存しない。通信時の認証ヘッダー、APIエラー本文、DM等の任意レスポンス項目は保存しない。作業用ロック・カーソルは無視対象の`.local/museum/`、原則ディレクトリ0700・ファイル0600。APIキーはプロセス環境だけから読む。

collect-x.mjsは実取得用のCLIを用意したが、ライブAPIとの疎通は未検証。実行には別途、開発者アクセスの準備・現在の条件の確認・人による費用判断が必要。通常は通信せず要求案を返し、通信には明示的な--execute、プロセス環境のX_BEARER_TOKEN、X_MAX_REQUESTS、X_MAX_POST_READSをすべて必要とする。キーをコマンド引数やファイルに書かない。

実行単位はアカウント＋指定期間。APIから不変ID・公開状態を確認し、full archiveをページングする。利用件数の制限は要求する主投稿の件数・リクエスト数の上限であり、ユーザー情報等も含む正確なドル上限を保証するものではない。自動課金・自動チャージの設定はしない。

1. 投稿ページを検査し、対象人物以外・不正な日時・範囲外・部分エラーを検出したら停止。
2. 正規化した資料とDB内の再開カーソルを同じトランザクションで保存。
3. 保存後だけ作業用チェックポイントを更新。次回はDBを正本として再開する。
4. 429・アクセス拒否・通信失敗時は取得済みカーソルを保持。制限回避や別アカウントへの切替をしない。
5. APIで最後まで列挙できてもstatusはenumeratedであり、削除済みも含む全履歴の完全取得とは報告しない。

## 保存後の削除・訂正

[X Developer Policy](https://docs.x.com/developer-terms/policy)は、保存データもX上の削除・変更に対応するよう求めている。無期限に全てを固定保存できるという前提にはしない。公開展示と研究用の保存は別で、全文の再配布も今回行わない。

ローカルのarchive_research.suppress_source(record_key,reason)は、全観測版の本文・公開メタデータ・指標を除去し、関連する編集案を削除して本文位置を伏せ、再取り込みを拒否する。内容を含まない監査を残す。APIによる定期的な状態再確認・削除通知の取り込みは未実装で、X本文の大量取得を継続運用する前の必要作業。この段階ではX本文は0件だった。後続の部分観測は下記の追補を参照。

## 追補：APIを使わないブラウザ観測

2026-11-08、ログイン済みChromeの期間検索から、廣川奈々聖の2015年5月1日と表示された5投稿を観測した。`.local/museum/browser/nanase-pilot.json` と非公開のローカルDBへ保存した。X APIへのリクエストは0件。これは画面のアクセシビリティ要約であり、UIラベルを含む部分記録（`partial`）で、原投稿の全文・改行・画像・動画・隠れた本文を取得したものではない。引用や画像の保存・公開はしていない。

画面表示の日付は `published_on` に保持し、正確な投稿時刻と表示タイムゾーンは未確認のため `published_at` はnull、`original_publication_confirmed` はfalseにする。投稿IDから時刻を補完しない。handleと固定URLは照合するが、不変ユーザーIDによる本人同定は未完了。ほか4名は未取得。Macのロックにより収集を中断しており、解除後に再開する。5投稿で当日や全履歴を列挙できたとは判定しない。

明示的に観測した公開投稿のJSON配列だけを次のコマンドで検査・保存する。ブラウザのCookie・認証情報を取り出さず、インポーター自体も外部へ通信しない。

```bash
node scripts/museum/import-browser.mjs .local/museum/browser/nanase-pilot.json
node scripts/museum/import-browser.mjs .local/museum/browser/nanase-pilot.json --apply-local

```

既定は検査のみ、`--apply-local` はローカルの非公開保存だけを行う。公開書誌や展示カードへの自動昇格はない。実調査のJSONL・CSV・取り込み案・画面写真もGitの対象外とし、公開リポジトリには合成テスト用データだけを置く。初回の件数表は履歴であり、現在のDB総数ではない。修正後の再取り込みによる総数は再実測する。

保存時は資料単位の共通ロックで取り込みと抑止を直列化し、抑止済み資料を再投入しない。該当箇所は取得版に、編集案は版・要約内容に対応したキーで保存し、変更後も過去版の根拠を上書きしない。API収集の失敗もDBに記録し、再開位置を維持する。日付は実在する暦日・時刻・オフセットを検査する。

外部通信しない収集・ブラウザインポートの単体テスト34件が成功した。全履歴の網羅性、ライブAPI互換性、削除・非公開化の継続確認、旧アカウントと不変IDの照合、バックアップ・復元は未完了。ブラウザ検索による取得可能範囲も今後記録し、検索結果がない期間を「投稿が存在しない」と扱わない。
