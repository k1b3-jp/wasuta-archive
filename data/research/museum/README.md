# ローカルの調査資料

未承認のJSONL・CSVとX取得計画はGit対象外です。実投稿、本文、作業用画面画像は公開リポジトリへ保存しません。

手元の調査用ファイルはこのディレクトリに保持し、取り込みはscripts/museum/plan.mjs --apply-localで非公開のローカルDBへ行います。新しいチェックアウトには実資料が含まれないため、編集プレビューは資料不足として表示します。

CIの検証にはscripts/museum/fixtures/exhibit.jsonの架空データを使います。原資料・アカウント・保存方法の説明はdocs/museum/collection.mdを参照してください。
